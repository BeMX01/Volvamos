# Volvamos a elegirnos ❤️

Experiencia romántica interactiva optimizada para celular.

## Archivos
- `index.html` — estructura de la experiencia.
- `style.css` — diseño, animaciones y adaptación móvil.
- `script.js` — estrellas, navegación, explosión final e interacción del segundo botón.

## Cómo probarla
Abre `index.html` en un navegador.

## Cómo subirla a GitHub Pages
1. Crea o abre un repositorio.
2. Sube `index.html`, `style.css` y `script.js` a la raíz.
3. En GitHub entra a **Settings → Pages**.
4. Selecciona **Deploy from a branch**.
5. Elige la rama principal y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la página.

No necesita servidor ni base de datos.
